# TechParts Web — продажа комплектующих для ПК и телефонов

Сайт на Java. Сервер написан на встроенном `com.sun.net.httpserver` (никаких библиотек и Maven),
все решения (скидки, рассрочка, риски, гарантия, рекомендации) принимает Java-код в `Logic.java`.
Браузер показывает только формы и ответы сервера.

## Запуск

**Windows:** дважды щёлкните `run.bat`. Сайт откроется в браузере сам (адрес http://localhost:8080/).
**Linux / macOS:** `bash run.sh`

Вручную:

```
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Нужен установленный JDK 11 или новее. Чтобы остановить сайт, закройте окно с программой (или Ctrl+C).
Запуск из IDE: откройте папку проекта и запустите класс `Main` (папка `web` найдётся сама).

**Вход:** `admin` / `1234` или `seller` / `5678`. После трёх неверных попыток вход закрывается на 15 секунд.

## Структура

| Файл | Назначение |
|------|-----------|
| `src/Main.java` | Веб-сервер, API, раздача сайта, вход (задание 5) |
| `src/Logic.java` | Вся логика: if-else, `&&`, `\|\|`, `!`, вложенные if, switch (задания 2–24) и итоговое решение (25) |
| `src/Params.java` | Проверка ввода: пустое значение, не число, выход за диапазон (задания 2 и 19) |
| `src/Result.java` | Ответ сервера (цвет, заголовок, строки) в JSON |
| `src/Session.java` | Кто вошёл, статус пользователя, журнал решений |
| `web/index.html`, `web/style.css`, `web/app.js` | Дизайн и интерфейс сайта |
